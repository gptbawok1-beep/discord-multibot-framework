PROMPT

Buat sebuah Discord Multi Bot Framework menggunakan Node.js 22 LTS, JavaScript (ESM), dan discord.js v14.

TUJUAN

Project ini harus mendukung 2 Discord Bot dalam satu project.

Bot menggunakan 2 Token Discord yang berbeda.

Namun kedua bot berbagi:

- Logger
- Utils
- Config
- Services
- Structures
- Handler

Semua dibuat satu kali (shared).

Jangan membuat fitur apa pun.

Bot hanya sebagai pondasi.

BOT2_TOKEN=
