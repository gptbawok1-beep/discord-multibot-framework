PROMPT — BOT 1 SETUP SYSTEM

Lanjutkan project Discord Multi Bot Framework yang sudah dibuat.

JANGAN mengubah struktur project.

JANGAN mengubah Core Framework.

JANGAN mengubah Handler.

JANGAN mengubah Shared System.

Fokus hanya membuat Setup System untuk BOT 1.

---

Tujuan

BOT 1 harus memiliki satu command utama:

/setup bot1

Command ini menjadi pusat seluruh konfigurasi BOT 1.

Semua fitur BOT 1 nantinya wajib menggunakan Setup System ini.

Jangan membuat command setup lain.

Semua konfigurasi dilakukan melalui Setup Wizard.

---

UI

Gunakan Discord Components.

WAJIB menggunakan:

- Embed
- Dropdown
- Button
- Modal

Jangan menggunakan command panjang.

Jangan meminta user mengedit file.

Semua dilakukan melalui UI Discord.
