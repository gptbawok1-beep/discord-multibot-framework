DROPDOWN CATEGORY

HOME BUTTON
Saat tombol 🏠 Home ditekan:
Embed kembali menjadi halaman utama Help Center.
Tidak membuat pesan baru.
CLOSE BUTTON
Saat tombol ❌ Close ditekan:
Nonaktifkan seluruh Button dan Dropdown.
Atau hapus pesan Help Center.
Gunakan metode yang paling sesuai dengan UI yang sudah ada.
DOKUMENTASI
Setiap kategori hanya menampilkan dokumentasi singkat.

💡 Tips

• Reply Message didukung.

• < > = Wajib

• [ ] = Opsional
Kategori lain cukup menampilkan ringkasan fitur dan cara penggunaan singkat.
AUTO UPDATE
Help Center harus membaca fitur yang sudah tersedia.
Jika suatu fitur belum diimplementasikan, jangan tampilkan pada Help Center.
Jika nanti fitur baru ditambahkan (Logs, Backup, Giveaway, Ticket Center, dll.), Help Center harus dapat menampilkannya tanpa mengubah konsep UI.
KOMPATIBILITAS
Help System harus kompatibel dengan:
Shared Core
Shared Setup Engine
Shared Config
Shared Storage
Auto Recovery
Permission System
Jangan mengubah arsitektur project.
Jangan membuat sistem dokumentasi terpisah.
Gunakan satu Embed yang terus diperbarui (edit message) agar UI tetap bersih, modern, dan konsisten dengan Setup System.
